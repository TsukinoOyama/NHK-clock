# NHK Clock — OBS 浏览器画面 v1.0.0

纯网页时钟画面，透明 1920×1080 画布，仅显示左上方的 NHK 风格时钟。没有设置面板和其他桌面悬浮窗。沿用原项目 `NHK.ttf`、东京时间 12 小时制、白字、黑描边、柔和阴影及原始位置尺寸。

## OBS 使用

将本文件夹作为静态网页部署后，把网页地址添加为 OBS「浏览器」来源，宽度设为 `1920`、高度设为 `1080`。也可在本机运行 `start.bat` 查看。

## 本机预览

需要 Python 3。双击 `start.bat` 会在本地启动网页服务并打开预览页。OBS 浏览器来源使用透明页面背景。
